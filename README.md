# 轉蛋機網頁 (Gacha Machine)

這是一個簡單的轉蛋機（抽獎機）網頁應用，獎品圖片是寫死在專案內，使用者需自行放置圖片檔案並修改 HTML 內容以更換獎品。

---

## 功能特色

- 使用本地靜態圖片作為獎品，無上傳功能。
- 轉蛋動畫效果，模擬抽獎過程。
- 支援多張圖片作為獎品，隨機抽取。

---

## 安裝與使用

1. 將專案下載或克隆到本地：
    ```bash
    git clone https://github.com/ee276776/Gacha.git
    ```

2. 將你想作為獎品的圖片放入專案資料夾內。

3. 修改 `index.html` 裡的獎品圖片內容來更換獎品。

4. 開啟 `index.html` 使用瀏覽器觀看轉蛋機。

---

## 使用說明

1. 確認圖片已放置於專案內，且 `index.html` 已依需求修改。
2. 點擊「抽獎」按鈕，開始轉蛋抽獎。
3. 抽獎結束後，會隨機顯示一個獎品圖片。
